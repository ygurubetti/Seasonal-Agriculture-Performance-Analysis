# Seasonal Agriculture Performance Analysis

## Overview
An empirical data analytics project investigating seasonal differences in agricultural productivity, water efficiency, pest risks, and economic viability across 4,000 Indian farms spanning Kharif, Rabi, and Zaid seasons.

## Repository Contents
* `Major_Project_Seasonal_Agriculture_Performance_Analysis.ipynb`: Complete data cleaning, feature engineering, visualizations, and Kruskal-Wallis hypothesis testing.
* `seasonal_agriculture_performance_dataset.csv`: Primary agricultural performance dataset.
* `VOIS_Major_Project_PPT.pptx`: Slide deck summarizing findings and strategic recommendations.

## Core Findings
* **Kharif**: Highest yield (5.63 t/ha) and profit (₹21,881/ha), but highest pest risk (54.5%).
* **Rabi**: Stable baseline yields (5.09 t/ha) and moderate profitability (49% profitable).
* **Zaid**: High thermal and water deficit leading to negative median returns (-₹13,760/ha) under flood irrigation. Drip irrigation remains profitable across all seasons.
* **Statistical Validation**: Kruskal-Wallis tests confirm seasonal differences are statistically significant (p < 0.001).
